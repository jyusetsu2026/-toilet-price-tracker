# トイレ商品 価格ランキング自動更新サイト

ZJ1／ピュアレストQR／アメージュ便器の主要な型番について、ネット上の価格を毎日調べて、
**商品ごと**に「安い店舗トップ5」「高い店舗トップ5」を店舗名つきで自動表示する仕組みです。

- `products.json` … 価格を調べたい商品の一覧（商品名と検索キーワード）
- `scrape_prices.py` … 価格を調べてランキングを作るPythonスクリプト
- `.github/workflows/daily-report.yml` … 毎日10:00(日本時間)に自動実行する設定
- `docs/index.html` … 実際に公開されるページ（GitHub Pagesで表示される）
- `docs/report.json` … ランキングの元データ

セットアップ手順は、同梱の `マニュアル.docx`（または manual.pdf）を参照してください。
中学生でも迷わないように、画面のイメージ図つきで説明しています。

## 商品リストを変更したいとき

`products.json` を編集して、商品名や検索キーワードを追加・削除してください。
次回の自動更新（毎日10:00）から反映されます。急いで確認したいときは、GitHubの
「Actions」タブから `毎日の価格レポート更新` を選んで「Run workflow」を押すと、
その場で実行できます。

## 注意事項

- 価格は検索サイトの表示から自動で拾っているため、実際の販売価格と多少ズレることがあります。
- 検索先サイトのページ構造が変わると、価格がうまく取得できなくなる場合があります。
  その場合は `scrape_prices.py` の調整が必要です。
